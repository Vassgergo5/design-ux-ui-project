**A fő feladat legrövidebb útja:** Home → Game page → kitűzött kategória → szűrt térkép → marker → „Mark as found”.

**Kivételes ágak:**
- nincs követett játék (E1);
- téves jelölés, Undo (E2);
- paywall (E3);
- offline mentési hiba (E4).

**Második flow:** elakadás egy puzzle-nél, fokozatos tippekkel. Fiók nélkül is végigjárható.
